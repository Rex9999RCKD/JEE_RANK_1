⚡ JEE RANK 1 — Planner & Spaced Repetition Tracker

JEE RANK 1 is an offline-first web application designed specifically for JEE Main & Advanced aspirants (Class 11/12 Physics, Chemistry, and Mathematics). It helps aspirants plan their daily study schedules, log mistake categories from test papers or coaching modules, and systematically review conceptual weak spots using a 3-day spaced repetition cycle.

🌟 Key Features

Daily Planning Hub: Designed for late night or early morning scheduling with structured task tables, time slot entries, priority tags, and automated hard deadlines.

Test Paper & Module Mistake Logging: Quickly log mistakes from tests or coaching modules categorized into:

CM (Conceptual Mistake): Automatically schedules follow-up Notes Revision + Question Practice tasks.

RM (Reading Mistake): Mindfulness logging for misread questions.

SM (Silly Mistake): Highlights formula or careless calculation slips.

3-Day Spaced Repetition System: Prompts you on the exact 3rd day after logging a mistake with an interactive prompt ("Do you want to revise this again after 3 days? Yes / No").

Permanent History Vault: Complete, persistent logging stored in browser localStorage with error distribution stats across CM, RM, and SM.

🚀 Quick Start Guide

Running Locally (Vite + React)

Clone the repository:

git clone https://github.com/YOUR_USERNAME/jee-rank-1.git
cd jee-rank-1


Install dependencies:

npm install


Start the development server:

npm run dev


Open your browser at http://localhost:5173.
